# Site de Comissões para @AstroArts

Arquivos:
- `index.html`: conteúdo e estrutura geral.
- `styles.css`: estilo visual.
- `script.js`: troca entre as abas.
- `img/`: crie esta pasta para colocar as imagens do portfólio.

## Como abrir
Clique duas vezes em `index.html`.

## Links direto pra redes sociais
No `index.html`, procure por:
- `https://www.tiktok.com/`
- `Discord`

Pode ser trocado pelos seus links e usuário.

## Como funciona o Discord

O Discord trabalha principalmente com nome de usuário para adicionar pessoas. Com isto, foi colocado outra solução:

-  Mostro o usuário e coloco um botão para copiá-lo.

`````
<a class="social-card" href="#" onclick="copyDiscord(event)">

  <span class="social-icon">
    <i class="fa-brands fa-discord"></i>
  </span>

  <span>
    <strong>Discord</strong>
    <small>@seuusuario</small>
  </span>

  <span class="arrow">⧉</span>
</a>
`````
